# E-commerce Customer Analytics & AI-Driven Campaign Pipeline

Практический Python-пайплайн для автоматизации аналитики клиентской базы интернет-магазина. Проект реализует сквозной процесс: от обработки сырых данных до предикативного моделирования и генерации персонализированного контента с помощью ИИ.

## 🛠️ Технологический стек:
- **Предиктивное моделирование:** CatBoostClassifier (градиентный бустинг от Яндекса) — прогнозирование вероятности оттока.
- **Кластеризация:** Scikit-Learn (алгоритм K-Means, StandardScaler) — сегментация базы.
- **Оркестрация контента:** Элементы LangChain — симуляция мультиагентной логики для генерации персонализированных офферов на основе метаданных клиента.
- **Data Engineering:** Pandas, NumPy.

## 🚀 Что реализовано в коде (Архитектура пайплайна):
1. **Слой обработки данных:** Генерация датасета транзакций (2000 профилей), расчет бизнес-метрик.
2. **Слой сегментации (K-Means):** Масштабирование признаков и автоматическое деление базы на 3 целевых сегмента (VIP, Новички, Уходящие).
3. **Предиктивный слой (CatBoost):** Обучение модели классификации для выявления клиентов с критическим риском оттока.
4. **ИИ-конвейер:** Автоматическое формирование адаптивного HTML-оффера для удержания клиентов на основе сегмента и прогноза оттока.
